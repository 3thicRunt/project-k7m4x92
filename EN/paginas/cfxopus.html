Model: CFX Opus 96 Dx
Type: Real-Time PCR
Website: Bio-Rad Laboratories, Inc.

Bio-Rad CFX Opus 96 Dx real-time PCR system, designed for the amplification and quantitative detection of nucleic acid sequences using real-time PCR (qPCR). The equipment features a 96-well reaction block, allowing simultaneous analysis of multiple samples and the performance of quantitative assays, gene expression analysis, melting curve analysis, and allele discrimination.

The Dx version was developed for regulated laboratory environments and includes features focused on data security and traceability, making it suitable for molecular diagnostic applications and the development and validation of real-time PCR methods.
